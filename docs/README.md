# Documentação do projeto

A documentação da migração acompanha o frontend na branch `feature/svelte-tailwind`. A branch `main` mantém a versão anterior enquanto a migração não for integrada.

## Por onde começar

| Objetivo | Documento |
| --- | --- |
| Instalar e executar o projeto | [README principal](../README.md) |
| Aprender Svelte e Tailwind e perceber o código | [Tutorial e introdução](TUTORIAL_SVELTE_TAILWIND.md) |
| Ver as etapas, branches, commits e correções | [Evolução da migração](EVOLUCAO_SVELTE.md) |
| Consultar os endpoints do backend | [Documentação da API](../backend/docs/README.md) |
| Executar a API simulada | [Guia do mock-server](../mock-server/README.md) |
| Executar as verificações e usar o Postman | [Guia de testes](../tests/README.md) |

## Conteúdo do tutorial

- Introdução ao papel de Svelte, Tailwind, Vite e Fetch API.
- Organização dos componentes e percurso dos dados.
- Estado reativo, filtro por curso e formulários.
- Operações de criação, consulta, edição e eliminação.
- Configuração da API local e da API do Render.
- Exemplos de correções e melhorias verificadas nesta migração.
- Perguntas de estudo com apoio de IA e formas de validar as sugestões.
- Exercícios para preparar uma apresentação e referências oficiais.

## Ver a versão correta no GitHub

Na página do repositório, selecionar `feature/svelte-tailwind` no seletor de branches. Esta branch reúne o código e a documentação. As branches de cada etapa mostram os respetivos estados intermédios.

Os endereços de produção no README dependem da branch configurada no alojamento. A existência do código numa branch de trabalho não significa que essa versão já esteja publicada no endereço de produção.
